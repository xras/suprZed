# Reporting issues in suprZed

suprZed is a personal, unofficial fork of Zed.
Bug reports and feature suggestions are welcome through this repository's Issues tab.
External pull requests are not accepted initially.

## Bug reports

Please check existing issues first. Include:

- A short description of the problem.
- Steps to reproduce it.
- What you expected to happen.
- What happened instead.
- Your operating system and the version shown in About.
- Relevant logs or screenshots.

Remove passwords, tokens, private paths and conversation content before posting.
Mention the agent and its version when reporting an agent terminal problem.

## Feature suggestions

Describe the task you want to complete. Explain how the proposed change would help.
A suggestion does not guarantee that a feature will be added.

## Maintenance and support

Code changes and merges remain under the maintainer's control.
There is no commitment to provide builds, releases or community support.
Discussions and the wiki will be disabled for the public fork.

## Contributing to upstream Zed

The [original Zed contribution guide](CONTRIBUTING-zed.md) applies to the upstream project.
It does not describe the contribution policy for suprZed.
